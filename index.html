1 Carregar arquivo CSV

Arraste um arquivo .csv para a área de upload ou clique nela para selecionar. Após selecionar o arquivo, clique em ▶ Carregar CSV.

Encoding: deixe em Auto-detectar para a maioria dos arquivos. Se aparecerem caracteres estranhos (ç, ã, é), selecione manualmente Windows-1252 ou UTF-8.
Delimitador: detectado automaticamente — pode ser vírgula ,, ponto e vírgula ; ou tabulação. O valor detectado aparece após o carregamento.
2 Arquivos grandes (acima de 900 MB)

Para arquivos maiores que 900 MB, o sistema ativa o modo de processamento em etapas para evitar travamento do navegador:

  1. O sistema lê apenas as primeiras 500 linhas para montar os filtros.
  2. Configure os filtros desejados (Regional, colunas etc.).
  3. Clique em ⚡ Processar — o arquivo é lido por inteiro aplicando os filtros durante a leitura, mantendo apenas as linhas que passam.
Quanto mais restritivo o filtro, menor o resultado em memória e mais rápida a exportação.
3 Filtros

Selecione uma coluna no seletor e clique em + Adicionar Filtro. Cada filtro é independente e todos são aplicados em conjunto (lógica E).

Tipo detectadoOperadores disponíveis
TXT TextoContém, Não contém, Igual a, Diferente de, Começa com, Termina com, Regex
NUM Número= Igual, ≠ Diferente, > Maior, ≥ Maior ou igual, < Menor, ≤ Menor ou igual, ↔ Entre
DATA DataDepois de, Antes de, Igual a, Entre (suporta formato dd/mm/aaaa)
O tipo da coluna é detectado automaticamente analisando as primeiras 200 linhas. Se ≥ 80% dos valores forem numéricos, a coluna é tratada como número.
4 Filtro de Regional

Aparece automaticamente quando o CSV contém uma coluna de localidade (Localidade, CódigoLocalidade, IdLocalidade etc.). Selecione uma Regional para exibir apenas as linhas daquela regional.

As regionais disponíveis são: BARREIRINHAS, CHAPADINHA, IMPERATRIZ, ITAPECURU, PEDREIRAS, PINHEIRO, PRES DUTRA, SAO JOAO DOS PATOS, SAO LUIS, SANTA INES.

5 Campos para Exportação

Por padrão, todos os campos são exportados. Para exportar apenas colunas específicas:

  1. Selecione um campo no seletor e clique em + Campo.
  2. O campo aparece como uma etiqueta #NomeDoCampo.
  3. Adicione quantos campos quiser — a tabela e a exportação passam a mostrar apenas eles.
  4. Para remover um campo, clique no × na etiqueta.
  5. Para voltar a exportar tudo, clique em Limpar.
6 Tabela e Ordenação

A coluna # à esquerda exibe o número original da linha no CSV (1-baseado). Clique no cabeçalho de qualquer coluna para ordenar — clique novamente para inverter a ordem.

Use Linhas por página nas configurações para controlar quantas linhas são exibidas por vez (50, 100, 200 ou 500).

7 Exportar para Excel

Clique em ⬇ Exportar para Excel para baixar as linhas filtradas em formato .xlsx. O arquivo gerado respeita os filtros ativos e os campos selecionados.

O Excel suporta no máximo 1.048.575 linhas por planilha. Se o resultado filtrado exceder esse limite, apenas as primeiras 1.048.575 linhas serão exportadas e um aviso será exibido.
